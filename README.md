# InLegalLaySum: A Novel Benchmark for Lay Summarization of Indian Legal Documents

Long Paper accepted at the **AACL-IJCNLP 2026 (Findings)**!

## InLegalLaySum Dataset

InLegalLaySum  (**In**dian **Legal** **Lay** **Sum**marization), a dataset comprising 9,570 judgements from the Supreme Court and several High Courts of India, paired with expert-written summaries in English. 

The full dataset can be found under https://huggingface.co/datasets/trishitasaha/InLegalLaySum . 

**Folder Structure -**
```text
InLegalLaySum/
├── InLegalLaySum_Train
    └── <id1>/
        ├── Judgement.txt                 # Original case judgement
        ├── Expert_Summary.txt            # Summary of judgement written by law practitioner
        └── Simplified_Summary.txt        # Summary generated by Gemini-2.0-Flash
├── InLegalLaySum_Test
    └── <id1>/
        ├── Judgement.txt         # Original case judgement
        └── Expert_Summary.txt    # Summary of judgement written by law practitioner
```

**InLegalLaySum_Train** 

It contains total **7470** samples.

**InLegalLaySum_Test**

It contains total **2100** samples. 

## Structure of Codes Folder

| File Name | Description |
|---|---|
| GPT_Generate_Summary.py | Generates simplified summary from the expert-written summary |
| SFT.py | Supervised Fine Tuning | 
| DPO_on_SFT.py | Direct Preference Optimization applied on the SFT model |
| Inference.py | Generates the final summary | 

## Structure of Evaluation Folder

| File Name | Description |
|---|---|
| Readability.py | Calculates readability scores - GFI, FKGL, FRE, DC, CLI |
| Rouge.py | Calculates quality scores - ROUGE-1,2,L | 
| Bert.py | Calculates the Bert score |
| SARI.py | Calculates the simplification SARI score | 
| LLM_As_Judge.py | Summary evaluation by an LLM performing as a Judge |
