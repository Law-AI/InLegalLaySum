# InLegalLaySum Dataset

InLegalLaySum  (Indian Legal Lay Summarization), a dataset comprising 9,570 judgements from the Supreme Court and several High Courts of India, paired with expert-written summaries in English. 

The full dataset can be found under https://huggingface.co/datasets/trishitasaha/InLegalLaySum . 

Folder Structure -

InLegalLaySum_Train
Each sample subdirectory contains 3 txt files -- Judgement.txt, Expert_Summary.txt and Simplified_Summary.txt  where Judgement.txt contains the original case judgment, Expert_Summary.txt is the summary of the judgement written by law practitioner and Simplified_Summary.txt is the lay summary generated by Gemini-2.0-Flash.
InLegalLaySum_Test
Each sample subdirectory contains 2 txt files -- Judgement.txt and Expert_Summary.txt where Judgement.txt contains the original case judgment, Expert_Summary.txt is the summary of the judgement written by law practitioner.
